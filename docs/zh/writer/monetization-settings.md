# 收益化设置

在 [收益化设置](https://quaily.com/dashboard/lists/@current/settings/payment) 中，你可以配置频道的变现方式。

## 包含内容

- 付款设置（法币 / 加密货币 / 作者自行托管支付）
- 收款设置
- 广告设置
- 与 Credits（点数）相关的功能开关

## 点数与收益化

以下收益化能力会依赖点数余额：

- 开启作者自行托管支付前，需要有足够点数
- 作者自行托管支付的平台服务费按订单从点数中扣除
- 额外发送配额、手动添加订阅者、从互联网导入文章按点数计费

点数管理入口： [Profile - Credits](https://quaily.com/dashboard/profile/credits)。
