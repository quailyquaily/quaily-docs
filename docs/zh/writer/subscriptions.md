# 订阅管理

在 [订阅者页面](https://quaily.com/dashboard/subscribers) 中，你可以管理频道成员。

## 可执行的操作

- 查看订阅者列表
- 按邮箱或会员类型筛选
- 修改成员订阅状态
- 移除订阅者

## 手动添加订阅者（Credits）

你可以在 Dashboard 里通过邮箱批量添加订阅者。

1. 打开 **订阅者** 页面。
2. 点击 **添加订阅者**。
3. 每行输入一个邮箱地址。
4. 确认后保存。

该功能按 Credits（点数）计费：

- 费用：20 Credits / 人
- 计费方式：按本次请求中新增人数扣费
- 点数不足时，请先前往 [Profile - Credits](https://quaily.com/dashboard/profile/credits) 充值
