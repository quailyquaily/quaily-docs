# 記事配信

Quaily で記事を書いた後は、読者へ配信できます。Quaily は Email、Telegram、Discord、LINE、Twitter/X、RSS など複数の配信チャネルを提供しています。

![](https://static.quaily.com/media/1gku5k35.webp)

## 配信設定

[配信設定](./channel-settings) を参照してください。

## 記事を配信する

記事編集ページのメニューで「Send」をクリックすると配信ダイアログが表示されます。「Send」を押すと読者へ配信されます。

**チャネル別配信**

ダイアログ内で、作者は配信チャネルを選べます。デフォルトではすべてのチャネルへ配信されます。特定チャネルだけに送りたい場合は、他をオフにしてください。

まだ未設定のチャネルは、設定ボタンからそのまま設定できます。

**予約配信**

配信ダイアログでは予約配信も設定できます。「Scheduled Sending」を押し、送信時刻を選ぶと予約配信になります。

指定時刻になると、自動的に配信されます。

## 追加配信枠（Credits）

1 日の配信枠を使い切っても、Credits を消費すれば追加配信できます。

- 料金: 追加 1 配信あたり 100 Credits
- 課金タイミング: 追加配信の実行時
- Credits が不足している場合は、先に [Profile - Credits](https://quaily.com/dashboard/profile/credits) でチャージしてください

## 配信履歴

「[Sending History](https://quaily.com/dashboard/delivery)」で記事の配信履歴を確認できます。

## プレーンテキストメール

Quaily は HTML 形式とプレーンテキスト形式の両方で記事を送信します。メールクライアントが HTML をサポートしない場合は、プレーンテキスト表示に切り替わります。

プレーンテキスト版では、記事の Markdown 本文が追加整形なしでそのまま使われます。
