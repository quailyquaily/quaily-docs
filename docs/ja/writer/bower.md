# Bower

Bower は、作者にとっての「居場所」のような機能です。友人の輪に近い感覚で、短文やちょっとした考えを共有し、読者と交流できます。

## Bower を有効にする

「[List Settings - General Settings](https://quaily.com/dashboard/lists/@current/settings/general)」で「Bower」を有効にしてください。

![](https://static.quaily.com/media/19zuwxzq.webp)

## Bower を投稿する

有効化すると、作者は Quaily の「Bower」ページで Bower を投稿できます。

![](https://static.quaily.com/media/qlxuy6yq.webp)

読者側では、作者の Bower を Quaily の「Bower」ページで閲覧し、その下にコメントして交流できます。

![](https://static.quaily.com/media/jp6u0yp1.webp)
