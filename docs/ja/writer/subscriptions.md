# 購読管理

[Subscribers](https://quaily.com/dashboard/subscribers) では、チャンネルのメンバーを管理できます。

## できること

- 購読者一覧の確認
- メールアドレスや会員種別での絞り込み
- 購読状態の更新
- 購読者の削除

## 購読者を手動追加する（Credits）

ダッシュボードからメールアドレスを指定して購読者を追加できます。

1. **Subscribers** を開きます。
2. **Add Subscribers** をクリックします。
3. 1 行に 1 件ずつメールアドレスを入力します。
4. 内容を確認して保存します。

この機能は Credits 課金です。

- 料金: 購読者 1 人あたり 20 Credits
- 課金方式: リクエスト内で追加した人数に応じた従量課金
- Credits が不足している場合は、先に [Profile - Credits](https://quaily.com/dashboard/profile/credits) でチャージしてください
