# データ移行

このページでは、他のプラットフォームから Quaily へ記事を移行する方法、または Quaily からデータをエクスポートする方法を説明します。

## 他プラットフォームからの移行

現在、Quaily は以下のプラットフォームからの記事または購読者の移行をサポートしています。

| Platform                | Posts | Subscribers |
| ----------------------- | ----- | ----------- |
| Medium                  | ✅    | ✅          |
| Substack                | ✅    | ✅          |
| Zhubai.love             | ✅    | ✅          |
| WordPress               | ✅    | ✅          |
| Bearblog                | ✅    | -           |
| Ghost                   | ✅    | -           |
| WeChat Official Account | ✅    | -           |

### 移行手順

**Medium**

Medium アカウントの URL を添えて、メールでご連絡ください。

**Substack**

Substack から全データをエクスポートし、メールでお送りください。

**Zhubai.love**

「[🚚 Migration Guide: From Zhubai to Quaily](https://quaily.com/blog/p/guide-migrate-from-zhubai-to-quaily)」を参照してください。

**WordPress**

「[Export Your Website’s Content](https://wordpress.com/support/export/)」に従って WordPress から XML をエクスポートし、メールでお送りください。

> [!NOTE]
> 投稿が公開状態であることを確認してください。保護された投稿はエクスポートされません。

**Bearblog**

Bearblog アカウントの URL を添えて、メールでご連絡ください。

**Ghost**

Ghost から全データをエクスポートし、メールでお送りください。

**WeChat Official Account**

WeChat Official Account にはエクスポート機能がありません。メールでご相談ください。

## インターネット上の公開記事を 1 本取り込む（Credits）

プラットフォーム全体の移行とは別に、ダッシュボード上から公開記事 1 本を URL 指定で取り込めます。

1. ダッシュボードで記事一覧を開きます。
2. **Import Post** をクリックします。
3. 記事 URL を入力し、コンテンツ利用に関する注意事項を確認します。
4. 取り込みを実行すると、下書きとして追加されます。

この機能は Credits 課金です。

- 料金: 1 記事あたり 10 Credits
- Credits が不足している場合は、先に [Profile - Credits](https://quaily.com/dashboard/profile/credits) でチャージしてください

## Quaily からデータをエクスポートする

「[List Settings - General Settings](https://quaily.com/dashboard/lists/@current/settings/general)」で「Export Data」を押し、少し待つと Quaily が登録メールアドレスへエクスポートデータを送信します。

エクスポートには、すべての記事と購読者データが含まれます。
