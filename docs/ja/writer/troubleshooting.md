# トラブルシューティング

## QQ Mail モバイルアプリでレイアウトが崩れる

QQ Mail のモバイルクライアントには、メール内に画像が含まれているとレイアウトが崩れる不具合があります。

Gmail や Outlook など、別のメールクライアントの利用をおすすめします。

## Cloudflare Recaptcha の認証を通過できない

Cloudflare Recaptcha 認証を通過できない場合は、次を試してください。

1. Chrome や Firefox など別のブラウザを使う
2. シークレットモード / プライベートモードを使わない
3. VPN を使う、またはネットワーク環境を変える
4. ブラウザ拡張機能をすべて無効にする

## 6 桁コードでログインできない

6 桁コードは 1 回しか使えません。一度使ったコードは再利用できません。

また、コードは 10 分で失効します。10 分を過ぎたコードも使えません。

必ず最新の正しいコードを使用してください。

## メールが届かない

メールが届かない場合は、次を確認してください。

1. 迷惑メールフォルダを確認する
2. 自分がリストオーナーなら、メール配信設定が有効か確認する
3. 中国本土のメールサービスを使っている場合、コンテンツ検閲の影響で受信できないことがあります
