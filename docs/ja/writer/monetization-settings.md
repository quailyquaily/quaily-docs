# 収益化設定

[Monetization Settings](https://quaily.com/dashboard/lists/@current/settings/payment) では、チャンネルの収益化方法を設定できます。

## 含まれる内容

- 決済設定（法定通貨 / 暗号資産 / self-hosted payment）
- 出金設定
- 広告設定
- Credits 関連機能の利用条件

## Credits と収益化

一部の収益化機能は Credits 残高に依存します。

- self-hosted payment を有効にするには十分な Credits が必要です
- self-hosted payment の手数料は、注文完了ごとに Credits から差し引かれます
- 追加配信枠、購読者の手動追加、インターネット記事の取り込みは Credits 課金です

Credits は [Profile - Credits](https://quaily.com/dashboard/profile/credits) で管理できます。
