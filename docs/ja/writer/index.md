# ライターガイド

このガイドは、[Quaily](https://quaily.com) での執筆と配信を始めるためのものです。

## 執筆と配信

- [オンライン執筆](./compose-online): Quaily のブラウザエディタで記事を書く方法。
- [記事配信](./delivery): 読者に記事を配信する方法。
- [Markdown 構文](./markdown-syntax): Quaily がサポートする Markdown 構文と拡張構文のリファレンス。
- [AI 機能](./ai): Quaily の AI 機能について。

## 読者とのやり取り

- [購読者管理](./subscriptions): 購読者を管理する方法。
- [コメント](./comments): 記事へのコメントを有効にする方法。
- [Bower](./bower): 短い記事やメモを共有し、読者と交流する方法。

## 収益化

- [収益化の準備](./monetization): Quaily で収益を得るための準備。
- [有料サブスクリプション](./premium): 読者向けの有料購読を設定する方法。
- [広告](./ads): 広告による収益化の設定。

## 設定

- [一般設定](./general-settings): サイト名、説明、アイコンなどの設定。
  - [分析](./analytics-settings): 組み込み分析と外部分析ツールの設定。
  - [独自ドメイン](./domain-settings): 独自ドメインを設定する方法。
  - [ウィジェット](./widget-settings): ウィジェットを設定し、自分のサイトに埋め込む方法。
- [配信設定](./channel-settings): Email、Telegram、Discord、LINE、X、RSS などの配信先設定。
- [収益化設定](./monetization-settings): 有料購読、広告、出金、決済などの設定。
  - [出金設定](./payout-settings): 収益受け取りの準備。
  - [決済設定](./payment-settings): 法定通貨や暗号資産を含む決済方法の設定。
  - [広告設定](./ads-settings): 広告設定と広告収益化。

## ツール

- [Obsidian プラグイン](./obsidian-plugin): Obsidian ノートを Quaily に公開する方法。
- [Quaily CLI](./quail-cli): コマンドラインから Quaily を操作する方法。

## その他

- [データ移行](./migration): 他プラットフォームから Quaily への移行、または Quaily からのエクスポート。
- [トラブルシューティング](./troubleshooting): よくある問題と対処方法。
